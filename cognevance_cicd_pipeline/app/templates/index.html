02. Containerization Architecture

Standardized packaging with unprivileged user execution and health checking.

Production Container Highlights

  • Base Image: Official python:3.11-slim for minimal attack surface.
  • Security: Non-root user appuser:10001 prevents privilege escalation.
  • Health Check: Built-in HEALTHCHECK monitors /health every 30 seconds.
  • Composition: Single-command deployment with docker-compose.yml.

Key CLI Commands

# 1. Build container image
docker build -t cicd-automation-app .

# 2. Run container in background
docker run -d -p 5000:5000 --name cicd-app cicd-automation-app

# 3. Check health and inspect logs
docker ps
docker logs cicd-app
docker inspect --format='{{.State.Health.Status}}' cicd-app
